2. Let your scale's app save to Health

In your scale's app, turn on Apple Health (usually under Settings → Apple Health or Connected apps) and allow it to write Weight. Weigh yourself once and check that it shows in the Health app under Browse → Body Measurements → Weight.

3. Build the Shortcut

In the Shortcuts app, tap ＋ to make a new shortcut called Send weight, and add these actions in order:

  1. Find Health Samples: Type Weight, Sort by Start Date, Order Latest First, Limit 1.
  2. Get Details of Health Samples: Value.
  3. Get Details of Health Samples (another one, on the same samples): Unit.
  4. Get Details of Health Samples: Start Date, then Format Date: Date Format ISO 8601, Include Time on.
  5. Get Contents of URL:
    Method POST. Headers:
    • Authorization = Bearer followed by your key (one space after Bearer)
    • ngrok-skip-browser-warning = 1
    Request Body JSON, with fields:
    • metric (Text) = Weight
    • value (Number) = the Value from step 2
    • unit (Text) = the Unit from step 3
    • recorded_at (Text) = the Formatted Date from step 4
  6. Get Dictionary Value message, then Show Notification with it (optional, so you see “Saved 72.4 kg to Weight.”).

Run it once by hand. The first time, iPhone asks to allow access to Health and to this website; allow both.

4. Run it automatically

In Shortcuts, open Automation → ＋ → App, choose your scale's app, tick Is Closed, pick Run Immediately, and choose the Send weight shortcut. From now on, closing the scale's app sends the newest weight. Sending the same weigh-in twice is fine; it's only saved once.
