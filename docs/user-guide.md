# User guide

## Accounts
Create an account from **Create an account** on the sign-in page. Everything you add (tasks, projects,
metrics, points) is private to your account.

## Tasks
**＋ Add task** opens the task form:

| Field | Meaning |
|---|---|
| Task | What needs doing |
| Project | Optional group (see Projects) |
| Starts / Due | When you plan to start and when it's due. The due date can't be before the start |
| Priority | Eisenhower-style: *not urgent/not important* (1) up to *urgent/important* (4) |
| Repeats | Does not repeat, every day, week, month or year |
| Tags | Comma-separated labels, e.g. `home, health` |
| Pomodoros planned / done | How many 25-minute focus sessions you expect, and how many you've done |
| Mark done when all planned pomodoros are finished | Finishes the task automatically after the last planned pomodoro |

Each task shows on one line with its checkbox, priority (P1–P4), project, repeat and tags. Click the line
to open it for dates, pomodoros and **Timer**, **Edit** and **Delete**. Tick the checkbox to mark a task done.

### Tabs
- **Today** (default): unfinished tasks due today or overdue, plus repeating tasks you haven't done yet
  this period. Overdue tasks get a red *Overdue* badge.
- **Repeating**: all repeating tasks.
- **One-off**: unfinished tasks that don't repeat.
- **Completed**: finished tasks.

### Filters
Project, priority, tag and search combine; change any of them and the lists update straight away.

### Repeating tasks
A repeating task starts over (not done, 0 pomodoros) when its period rolls over: the next day, the next
calendar week (Monday), the next month or the next year. This happens the next time you open the task list.

## Pomodoro timer
**⏲️ Timer** on a task opens a 25-minute focus timer. Each completed pomodoro is counted on the task.

## Projects
**Projects** in the top bar lists your projects with a progress bar (finished / all tasks). From there you
can add a task straight into a project, edit it, archive it (hides it from the task form) or delete it.
Deleting a project keeps its tasks; they just have no project afterwards.

## Metrics
**Metrics** tracks any value over time, such as body weight or hours slept. Create a metric with a name and
unit, then add entries (value, time, optional note). Each metric shows its latest value, the change since
the first entry, the lowest and highest values, and a chart.

## Insights, points and levels
**Insights** shows your activity for the last 30 days (tasks finished and pomodoros per day), finished vs.
open tasks by priority, and project progress.

- Finishing a task earns **5 × its priority** points (5–20). Each pomodoro earns **2**.
- Un-ticking a finished task takes its points back.
- Every **100 points** is a new level.
- Your **streak** counts consecutive days with at least one finished task or pomodoro. Yesterday still
  counts, so a streak isn't lost before you've done anything today.
- **Badges** unlock for milestones such as your first task, 10 and 100 tasks, 50 pomodoros, and 3-, 7- and
  30-day streaks.

Your level, points and streak are always shown in the top bar.
